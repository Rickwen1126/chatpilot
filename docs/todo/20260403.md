### 已定案

- `route_id` 是 storage unit
- `route_group` 是 sharing/query unit
- `route_group` 是一級配置，但不放 `members`
- membership 由 `binding.observation` 推導
- `observation` 掛在 `binding`，不是 `chatbot`
- `reply_policy` 先收成：
  - `silent`
  - `addressed`
  - `smart` 留 future
- `addressed` 的語意：
  - 私聊通常等於每句都 addressed
  - 群組依 mention / keyword / slash / 平台規則判定
- `binding.observation` 最小 schema 先只留：
  - `capture.group`
  - `capture.profile`
  - `consume[]`

### 暫不併入這一輪

- `follow` / `join` discovery onboarding
- event schema 細化
- bot-level persistent memory
- `smart` reply policy 實作
